O WayMate é um projeto de óculos inteligentes desenvolvido para ajudar pessoas com deficiência visual a identificar obstáculos durante seus deslocamentos.

Conheça o projeto

Sobre o WayMate

A locomoção pode ser um desafio para pessoas com deficiência visual, principalmente em locais com obstáculos inesperados. Pensando nisso, o WayMate busca oferecer uma alternativa tecnológica que ajude a tornar os deslocamentos mais seguros.

O projeto utiliza sensores para identificar objetos próximos e emitir alertas que ajudam o usuário a perceber a presença de possíveis obstáculos.

Como funciona?

01. Detecção

O sensor identifica obstáculos que estejam próximos dos óculos.

02. Processamento

O sistema recebe as informações do sensor e verifica a distância do objeto.

03. Alerta

O usuário recebe um aviso sonoro ou uma vibração, dependendo do modo escolhido.
